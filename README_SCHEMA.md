# Fluente-Mente — Schema e struttura

La pagina pubblicabile è una directory Jekyll con `index.md`.

Il front matter minimo operativo contiene:

- `content_id`
- `content_type`
- `title`
- `description`
- `permalink`
- `canonical`
- `status`
- `index`
- `follow`
- `sitemap`

Gli articoli didattici possono aggiungere gli elementi specifici definiti dalla relativa Master Architecture.
